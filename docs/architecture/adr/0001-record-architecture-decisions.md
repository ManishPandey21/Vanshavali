# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-09-25

## Context
Vanshavali involves hard-to-reverse choices about genealogy modelling, privacy, property and
provenance. Without a record, decisions get re-argued and their reasoning is lost.

## Decision
Record significant decisions as ADRs in `docs/architecture/adr/NNNN-title.md`, each with the
sections Status / Context / Decision / Consequences / Alternatives. Statuses are *Proposed →
Accepted → Superseded by ADR-XXXX*. Stress-test each ADR (grill-me) before accepting it.

## Consequences
Every PR that changes one of the areas listed in `CLAUDE.md` rule 2 must link an ADR.
