# Golden panchang tables (ADR-0022 §9)

One JSON file per convention (`purnimanta.json`, `amanta.json`). **Rows are entered by a reviewer
from a published panchang, never generated by the engine under test.** No table ships yet, so no
convention is offered to families (`golden_verified` is false in `data/conventions.json`, and the
test suite refuses a verified convention without a passing table).

Required coverage per convention: at least 3 years (one with an adhik masa, several kshaya and
vriddhi tithis), Varanasi, Delhi, Pune and Bengaluru, and London and San Francisco.

Row format:

```json
{
  "source": {"panchang": "…", "edition_or_url": "…", "page": "…", "retrieved": "YYYY-MM-DD"},
  "rows": [
    {
      "city": "varanasi",
      "date": "YYYY-MM-DD",
      "tithi_at_sunrise": {"paksha": "krishna", "tithi": 8},
      "amanta_masa": "bhadrapada",
      "is_adhik": false,
      "tithi_end_local": "HH:MM",
      "note": "optional: a documented divergence between sources"
    }
  ]
}
```

Tolerance: the civil day, the tithi at sunrise and the month must match exactly; a tithi's end
time within 2 minutes of the source.
